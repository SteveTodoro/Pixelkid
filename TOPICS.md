# Year 3 Lesson Library — Topic Ideas (UK National Curriculum)

Older lessons are about 30–40 minutes: Start → Recap of last lesson (or a Warm-up when it starts a new topic) → Read → Video quest → Game → Read → Video quest → Game → Brain Break → Boss Battle quiz.

**Compact format (15–20 minutes, being piloted in Suffix Squad):** Start → Recap / Warm-up → Read → Video quest (ONE video) → Game → Read → 🕹️ pick-a-game Arcade (`pick: true`) → (English: Spell Test) → Boss Battle. No brain break and no automatic Games stage (`midBreak: false`), because the Arcade is the fun break. Set `layout: 2` on a lesson whose stages were rearranged, so saved progress starts again from the top.

**Force Lab (`forces` game):** hands-on physics. Gesture tasks `{ thing, label, force: 'push'|'pull', effect, yes }`: swipe ▶ = push (away from you), swipe ◀ = pull, tap = press (push). Slide tasks `{ slide: 'ice'|'wood'|'carpet'|'grass'|'sand', thing, label }`: flick so friction stops it in the green zone. Magnet mode: `hold: '🧲', snap: true, noTap: true, words: {...}` relabels the arrows (e.g. ATTRACT/REPEL, STICKS/NO STICK) and tasks add `holdTag`/`tag` for facing poles (e.g. 'N ▶', '◀ S'). Used in Magnet Magic (will it stick? + pole power), Pushes, Pulls & Friction (rounds) and as a hands-on warm-up in recap stages via `review.game`. Keep task labels free of the words push/pull.

**Simulated experiments (for when real tools aren't available):** `ramp` (Ramp Lab: stack 1–4 books, pick a floor from towel/sand/grass/carpet/wood/tiles/ice, let the car go, results table; `missions: [{ text, need: { surface, height }, yes, ask }]`) and `garden` (Seed Garden: drag seeds into pots, drag pots between sunny window and dark cupboard, pour from the watering can, fast-forward 2 weeks; `missions: [{ text, pots, goal: 'healthy'|'lightTest'|'waterTest'|'dryTest', yes, fix, ask }]`). Add tactile interaction wherever possible in new lessons.

**Plants style:** mascot Professor Bolt, `finishAch: 'gardener'` (Green Thumb, unlocks the gardener's straw hat); shop pet Sunny the sunflower. Bosses so far: Weedzilla, King Gloom, Mowbot 3000. Shop pets: Sunny the sunflower, Busy bee.

**Rock Lab (`rocklab` game):** test rock samples like a geologist. `rocks: ['granite', 'marble', 'slate', 'sandstone', 'chalk', 'pumice']`, `tests` (default all): `look` (magnifying glass: crystals, veins, layers, grains, powder or holes), `scratch` (drag the paper clip across the rock; chalk powders, sandstone/pumice crumble, slate/marble get a thin line, granite nothing), `water` (permeable rocks soak the drop up), `float` (only pumice floats). `missions: [{ text, need: ['chalk:scratch', 'granite:scratch'], yes, ask }]`; every test adds a row to the results table. Rocks lessons use Professor Bolt; bosses so far: Gnash the Gravel Gobbler, Pterry the Fossil Snatcher, Cementor the Cement Mixer.

**Fossil Dig (`fossildig`):** brush (drag) the rubble off a cliff of rock layers to uncover fossils. `layers: [{ rock: soil | sandstone | mudstone | limestone | chalk | shale, age }]` (top = newest), `missions: [{ text, fossils: [{ kind: ammonite | trilobite | fern | fish | tooth | footprint | bone | shell, layer, x: 0–1 }], need, yes, ask }]`. Finds go in a table with their layer and age – good for "deeper is older" investigations.

**Soil Lab (`soillab`):** `soils: ['garden', 'sandy', 'clay']`, `tests: ['shake', 'drain']` (default all). Shake jar: drag the jar side to side (or "Shake it for me"); the soil swirls, then settles into stones, sand, silt and clay bands (sized by each soil's recipe) with humus floating. Drain test: drag the watering can over the funnel to pour 100 ml; sandy lets 85 ml through, garden 55 ml, clay 15 ml (a puddle stays on top). `missions: [{ text, need: ['garden:shake', 'clay:drain'], yes, ask }]`; every test adds a row to the results table. Lives in `shared/engine/earth.js`.

**Bee Flight (`pollinate` game):** touch/drag and the bee flies there; hovering on a flower's middle drinks nectar and picks up its pollen (dots in that flower's colour), and pollen delivered to a DIFFERENT flower of the SAME kind pollinates it (petals drop, it grows an apple, seed pod or seed head). `missions: [{ text, flowers: ['apple' | 'poppy' | 'sunflower' | 'daisy', …], goal: 'collect' | 'all', yes, ask }]`.

## 🔢 Maths
- Place value to 1,000: hundreds/tens/ones, zero as a place holder, partitioning (incl. non-standard), numbers in words, 10/100 more or less, comparing, number lines to 1,000 ✅ *(Place Value Party)* · counting in 4s, 8s, 50s and 100s
- Adding & subtracting 3‑digit numbers: mental (add ones/tens/hundreds, crossing a ten), estimating, the inverse, column method with exchanging ✅ *(3-Digit Add & Subtract)*
- 3, 4 and 8 times tables; multiplication & division word problems
- Fractions: unit fractions, tenths, equivalents, comparing, adding with the same denominator
- Money: UK coins and notes, £1 = 100p, writing £1.50, counting coins, adding prices, giving change by counting on, fewest coins, bartering and the history of money ✅ *(Money Market)*
- Time: o'clock, half past, quarter past/to, 5‑minute past/to ✅ *(Tick Tock Time)* · to the minute, a.m./p.m., midnight/midday, Roman numeral clocks, seconds/minutes/hours ✅ *(Clock Quest: To the Minute)* · 24‑hour clock, days/weeks/fortnights, days in each month (knuckle trick), leap years ✅ *(Night & Day: The 24-Hour Clock)* · durations: start/end times, hopping on a time line, end and start times, timetables ✅ *(How Long? Time Hops)*

**Place Value Blocks (`placeblocks`):** hundreds, tens and ones on a place value mat (`cols: ['t', 'o']` for 2-digit warm-ups). Tap or drag a block from the supply onto the mat; tap one on the mat to take it off. `missions: [{ text, make: 347 } | { make, start: 316 } (change a number, e.g. 10 more) | { read: 253 } (type the number the blocks show; after 2 misses each column's digit shows) | { start: { h: 1, t: 3, o: 14 }, goal: 'tidy' } (swap 10 ones for a ten) | { start: 36, make: 36, need: { t: 2, o: 16 } } (non-standard partitioning: needs `break: true` on the round, which adds 🔨 Break buttons)], yes, ask`. `add: true` on a mission lets a column go past 9 while adding (13 ones, then swap). Place Value Party uses Professor Bolt (Tock is for time lessons); boss Jumble the Jester.
**Column Sums (`columnsum`):** the written column method. `sums: [{ a: 268, b: 145, op: '+' | '-' }]` (answers up to 999; never exchange from a 0). Work from the ones on a keypad; when adding makes 10 or more, tap the carry box over the next column; when subtracting with a top digit too small, tap the next column's top digit to exchange. Hints name the exact step; subtraction answers show the inverse check. Used in 3-Digit Add & Subtract (boss Captain Carryless).
**Shop Till (`shop`):** tap or drag UK coins (copper 1p/2p, silver 5p/10p, seven-sided 20p/50p, two-tone £1/£2; add `coins: [..., 500, 1000]` for notes) onto the counter, then Check. `missions: [{ text, customer: emoji, pay: 75 (make exactly 75p; `fewest: true` = with the fewest coins) | buy: [{ name, emoji, price }] (add up, pay the total) | buy + given: 100 (give the change), yes, ask }]`. The counter total only shows after two misses; change hints count on from the price. Works as an `investigate` test. Used in Money Market (boss Pinchy the Penny-Pincher).

**Maths Mine style:** load `../shared/clock.js` for clock lessons (`Clock.svg('3:45', { halves, ring: 'pastto' | 'minutes', roman })` for pictures, `Clock.words()`). Mascot Tock the Clock-Bot (`Pixel.sprites.tock`) for time lessons; `finishAch: 'miner'` unlocks the miner helmet. Bosses so far: Count Clockula, The Time Bandit, The Night Owl, Slowcoach the Snail, Jumble the Jester, Captain Carryless, Pinchy the Penny-Pincher. Shop items: Sleepy nightcap, Speedy snail. Numbers inside clocks, LCDs and arcade labels use the Lexend font, because in the pixel font a 5 looks like an S.
- Measuring: m/cm/mm, kg/g, l/ml; perimeter
- Shapes: 2D & 3D, right angles, horizontal / vertical / parallel / perpendicular lines
- Statistics: bar charts, pictograms, tables

## 📚 English
- Prefixes (un‑, dis‑, mis‑, re‑, sub‑, super‑, auto‑) ✅ *(Prefix Power)* and suffixes (‑ful, ‑less, ‑ly, ‑ous, ‑ation) ✅ *(Suffix Squad)*
- Homophones (there/their/they're, hear/here, to/two/too …) ✅ *(Homophone Hunters)* and *a* vs *an* ✅ *(A or An?)*
- Conjunctions (and, but, or, so, because, when, before, after, while, until, if) ✅ *(Conjunction Junction)* · adverbs of time
- Prepositions; present perfect tense
- Punctuating speech with inverted commas ✅ *(Speech Marks Squad)*: speech bubbles → speech marks, punctuation inside, capital letter, speaker first or last, exact words vs reported speech, better words for said
- Reading genres: fairy tales, myths & legends (what a myth is, the Theseus story in parts, comparing versions, feelings from clues, gods & monsters) ✅ *(Theseus & the Minotaur)*, poetry (rhyme, rhythm/syllables, onomatopoeia, alliteration, similes, verses, performing) ✅ *(Poetry Playground)*, non‑fiction (headings, glossaries)
- Reading skills: predicting, inferring feelings, finding the main idea, dictionary skills

**Word Kingdom style:** mascot Quill the Wizard (`Pixel.sprites.wizard`), boss Grumblegob the spelling goblin (`Pixel.sprites.goblin`), `finishAch: 'speller'` (unlocks the golden quill). Keep grammar explanations to one or two short sentences per card. **Every English lesson has a dedicated 🪄 Spell Test stage** (a `game` stage with `icon: '🪄', kind: 'Spelling test'`) placed before the brain break, with three rounds: a warm-up (`spelltest` `peek` or `fix`), the real test (`spelltest` `listen`, 8–10 words from the lesson or age-suitable verbs/adjectives), and a Letter Blaster (`invaders` spelling waves). Vary the `scene` between lessons (potion: Prefix Power · egg: Suffix Squad · castle: Homophone Hunters · rocket: A or An? · train: Conjunction Junction · balloon: Speech Marks Squad · snowman: Poetry Playground · ship: Theseus & the Minotaur). Word Kingdom lessons can bring their own boss: Grumblegob (prefixes, suffixes), Echo the Mix-Up Ghost (homophones), Snatchit the Magpie (a/an), Stopsy the Full-Stop Gremlin (conjunctions), Blabber the Bubble-Popper (speech marks), Prosey the Plain-Word Troll (poetry), The Minotaur (Theseus).
**Syllable Drum (`syllables`):** tap the drum once per syllable, then check. `items: [{ word: 'butterfly' (or a short line), parts: ['but', 'ter', 'fly'], emoji }]`. Two misses show the beats; 🔊 says the word.
**Speech Marks (`speechmarks`):** tap the gaps where the speech marks go. `items: [{ text: '“Look out!” shouted Sam.' (the answer, with curly marks), who: emoji | 'me', bubble: true (show the spoken words in a speech bubble first), hint, why } | { text, none: true, why } (reported speech: needs no marks; any `none` item adds a "No speech marks needed" button to every item)]`. Words and punctuation get separate gaps, so "punctuation goes inside" can be got wrong and explained. Two wrong tries show the answer. Shop pets: Echo the ghost, An octopus.

**Boss encounter:** before the fight, an Undertale-style text box plays `lines.prefight`: three lines, [boss, player, boss]. The boss taunts (e.g. "Do you really know your stuff, or were you just spamming the buttons?"), the player answers back with something the lesson taught, and the boss has the last word. The text types itself out (tap to finish a line, tap again for the next one; Skip jumps to the fight). It plays once per visit; a retry or rematch goes straight to the fight. Every boss gets its own lines in its own voice.

**Boss ammo & dodge rounds:** `attack` can be one emoji, a list (`['💧', '☂️']`) or `Pixel.svg` pictures (e.g. a ninja star); `spin: true` makes them twirl. Planned next: boss drops, a move themed on a boss that beating it unlocks.

**Music:** `shared/music.js` plays looping chiptune themes built in Web Audio (no sound files): one map theme per world (`map-<world>`, on the home page, starting on the first tap) and `boss` (the boss battle; it speeds up when the boss gets angry and stops for the finishing move, on game over and when you leave the stage). The home page 🎵 button sets `y3:settings.music`; the lesson 🔊 mute silences music too.

## Making a new lesson
1. Copy `science/magnets.html` into the right subject folder (e.g. `maths/fractions.html`).
2. Change the `window.LESSON = { … }` data: `id`, `subject` (`science` / `maths` / `english` / `future` / `wonders` / `world` sets the colours), title, mascot, glossary, and the stages.
3. Add it to the `LIBRARY` list in `shared/library.js` by setting its `file`.

**Stage types:** `welcome`, `review` ("Last time…" recap: `from: { title, emoji, url }`, `facts`, `questions`; or a 🔥 warm-up when `from` has no url — see **Roads, recaps and warm-ups** below), `read`, `video` (YouTube `id` + questions), `game`, `break` (wiggle moves and/or a `tryit` activity, plus 🕹️ Brain Games – boss tic-tac-toe, steady hand, maze, hangman (uses the lesson's glossary words as a theme) – added automatically; `games: ['maze']` picks some, `games: false` turns them off), `quiz` (add `boss` for a boss battle).
**Quick brain-games break:** the engine adds a short `Games` stage (pick Tic-Tac-Toe, Steady Hand, Maze or Hangman) after the first game stage of every lesson. Set `midBreak: false` on the lesson to skip it, or pass `{ title, say, games }` to customise it.
**Pick-a-game stage (`pick`):** a `game` stage with `pick: true` (or `{ title, say, again }`) shows its `rounds` as cards (each round adds `emoji` and a one-line `blurb`). The player chooses one; winning any one completes the stage, and the others stay open to play for fun (finished ones get a ✔). Mix kinds of game (e.g. a shooter, a puzzle, a skill game). `steadyhand` (the brain-break Steady Hand as a round: the first win finishes it) is a pure skill game the parent asked for as one choice; keep the other choices doing the lesson's thinking. (A goblin-themed `labyrinth` was tried in Suffix Squad and judged lacklustre.)
**Saved progress after a rearrange (`layout`):** saved progress keeps stage numbers, so after adding, removing or reordering stages, raise the lesson's `layout` (e.g. `layout: 2`). Progress saved under an older layout starts again from the top; gems, stars and badges stay.

**Game types available:** `sort`, `match`, `label`, `order`, `truefalse`, `questions` (read a table/picture, then answer), `wordsearch` (`words`, `size`), `crossword` (`entries` of `{answer, clue}`; the layout is built automatically), `trainai` (teach the robot with labelled examples, then judge its guesses), `pixelcopy` (copy a target sprite on a pixel grid; `mirror: true` for symmetry; "I'm finished!" scores a % and unlocks the next round; `choices: [{ label, level 1–3, target, colors, names, tips, say, done }]` lets the player pick what to draw), `pixelstudio` (free drawing with a design `brief`; saves to the device's gallery and downloads PNGs), `poster` (drag-and-drop poster editor with a `start` layout, `brief` and `checklist` — items with `auto: bigTitle | contrast | clutter | picture | inside` tick themselves)
**Spelling:** `spelltest` (`words` of `{word, sentence: 'The ___ …', clue, hint, wrong}`; `mode`: `listen` = hear the word in a sentence (British text-to-speech) | `peek` = look, cover, write, check | `fix` = correct the misspelt `wrong` word; `scene`: `potion` (ingredients fill a cauldron) | `egg` (cracks a dragon egg until it hatches) | `castle` (builds a castle tower row by row) | `rocket` (fuels a rocket that blasts off) | `train` (couples a carriage onto the engine for each word) | `balloon` (fills a hot-air balloon band by band, which floats away at the end) | `snowman` (builds a snowman from the bottom up, hat last) | `ship` (builds Theseus's ship under a black sail, which turns white when it's finished); `prize` names it). First-try spellings earn a gem, two misses reveal the word to copy, and the report card offers a practice re-run of tricky words.
**Arcade games:** `runner` (Lane Runner – the default word-sorting arcade round: the avatar runs by itself and the words come in pairs, one per lane (top / bottom); tap a half, swipe or use ⬆ / ⬇ to pick the right one. Same data as the platformer: `prompt`, `items: [{ label, ok, why, yes }]`; right and wrong words are paired automatically, and a wrong pick shows `why` and comes round again. `speed` optional), `invaders` (`waves` of `{prompt, items:[{label, ok, why}]}` – shoot the right answers; or spelling waves `{spell, clue, decoys}` – shoot the letters in order; like the arcade original the aliens drop zig-zag bombs to dodge – a hit stuns the ship for a second but never costs gems, a wave with no hits earns a bonus gem – and a mystery UFO flies over now and then: shoot it for a bonus gem, 3 per game at most), `platformer` (`prompt`, `items`, optional `ice: true` – collect right answers, reach the flag; retired from lessons in favour of `runner` because long words were hard to jump), `blocks` (Block Builder: a `map` of terrain letters g/d/s/w with R = robot and F = flag, plus `blocks` with counts; blocks with `sinks: true` splash into water – build a path so the robot reaches the flag), `labyrinth` (walk a dark maze, lit only around the hero, with Ariadne's red thread trailing behind: `map` rows of `#` wall, `.` floor, `S` entrance, `M` monster, `1`–`9` gates; `gates: [questions]` (gate n asks the nth, and opens once answered), `monster` (the question that beats it), `monsterPic`, `monsterSay`, `outSay`, `done`. Tap a square to walk there along squares already seen, drag the hero, or use the arrows. After the monster, walk back to the entrance along the thread. Make the map a tree (no loops) so no gate can be walked round. A maze that isn't Theseus's sets `words: { door, find, beat, back, out }` for its door emoji and status lines). Put one arcade round in every lesson. — a game stage can have several `rounds`.
**Day Dial (`daydial`):** drag the sun and moon along a whole day; a clock, the 12-hour and the 24-hour time follow along. `missions: [{ time: '19:30', show: '12' | '24' | 'words', hide: ['24'], yes, ask }]` (one readout stays 🔒 locked so the child converts), `events: [{ time, emoji }]`, `step`, `nudge`, `start`. Hints spot the a.m./p.m. mix-up.
**Time Hops (`timehops`):** a frog hops along a time line. `missions: [{ from: '3:45', to: '4:20' } (how long? then pick the total – the wrong options include the take-away-like-normal-numbers trap) | { from: '5:50', add: 25 } (when does it end? includes the "5:75" trap)]`, `hops: [60, 10, 5, 1]`, `clock: '24'`.
**Knuckle months (`knuckles`):** tap along two pixel fists, knuckle = 31 days, dip = 30 (February 28); `ask` questions afterwards.
**Clock game:** `clock` with `mode: 'set'` (drag the hands to a time; `times` (each can add `start` and an `ask` puzzle, e.g. a start time + a duration), `show: words | digital | both`, `step` 5 or 1, `helper: on | off | none` for the PAST/TO ring, `roman: true`, `start`) or `mode: 'read'` (read the clock: tap the hour, type the minutes). Hints spot the classic mistakes (wrong side of the clock, quarter to the wrong hour), and after 2 misses faint ghost hands show the answer. The `match` game takes `html: true` for clock pictures.
**Proofreader:** `fixit` (`sentences` of `{ text, wrong, fix, options, why, hint }` or `{ text, ok: true, why }`; tap the wrong word, then drag the right word onto it; `noOk: true` hides the "No mistakes!" button). Works well in recaps via `review.game`.
**Quiz types:** `mcq`, `tf`, `gap`, `order` (label the two ends with `ends: ['SHORTEST', 'LONGEST']` – default FIRST / LAST; `start: true` fills in step 1 for long sequences; in a boss fight the first slip in an order question is a free hint). Only use `order` when there is ONE obvious order a child can see (time, size, a life cycle, a word growing); never for a list of method steps where two could swap. Set `optionsHtml: true` to use pictures (HTML) as the answer buttons.
**Pixel sprites:** `Pixel.sprites.robot / magnet / magnetron`, or draw your own with `Pixel.svg(rows, palette)`.
**Video tip:** check a video exists and read its transcript before writing questions about it.

**Hands-on question types (work in quizzes, video quests, the `questions` game, boss battles AND as reading-page `check`s):**
- `evidence` — tap the sentence that proves it. `{ q, answer: 'a few words from the right sentence' }` (or a list when several sentences prove it). As a reading check the page's own sentences become tappable; anywhere else add `passage: 'text'` (or a list of paragraphs).
- `hotspot` — tap the right place on a picture. `{ q, img: svg or emoji, spots: [{ x, y, r, label }] (% of the picture; r = radius, default 12), answer: spot index or a list of right spots }`. A wrong tap shows that spot's `label`.
- `slider` — drag a marker on a number line. `{ q, min, max, step, answer, tolerance, unit, ticks (gaps, default 10), from, endsOnly (label only the ends), hideValue (for estimating), format: v => … }`. A wrong answer says "too high" or "too low".
- `oddone` — odd one out, then WHY. `{ q, items, answer, why, reasons, reason }`.
- `build` — tap tiles into a word or sentence. `{ q, answer: ['un', 'happy'], extra: ['re'] (decoys), join: '' (word) or ' ' (sentence) }`.
- `type` — write the answer. `{ q, answer: '12' or ['colour', 'color'], before, after, placeholder }`. Capitals, spaces and punctuation are ignored.
- `setclock` — drag the clock hands to show a time (clock lessons; it loads the time part and needs `shared/clock.js`). `{ q, time: '3:45', step: 5, start: '12:00', helper: true (the PAST / TO ring) }`. A wrong try says what's wrong with the hands (wrong side, quarter to the wrong hour…); after two, faint hands show where to go. **In clock lessons, prefer it to "long hand on the 9, short hand nearly at the 6 – what time is it?" sentence questions**: the parent wants him answering with the clock hands as much as possible.
- `predict` — guess first (never marked wrong), see the reveal, then explain. `{ q, options, answer (the real outcome, optional), reveal, revealPic, then: { q, options, answer, explain } }`.

**Comic pages:** a read card can use `comic: [{ who: 'mascot' | 'me' | emoji/svg, name, say, pic }]` instead of `text` – each line becomes a comic panel with a speech bubble ('me' is the child's own avatar and name). Checks (including `evidence`) work the same. Good for explaining an idea as a conversation (see the "Meet AI" card in `future/ai.html`).
**Mystery word (`mystery` game):** `words: [{ word, clues: [hardest first, usually 3], options (optional: tap instead of type), explain }]`. Clues appear one at a time; solving on clue 1 = 3 gems, clue 2 = 2, then 1. A wrong guess shows the next clue; after two wrong guesses the first letter is given. Use it instead of a word search or crossword.

**Roads, recaps and warm-ups (the home page quest map):** each world on index.html is a road. A lesson follows the one listed before it in `LIBRARY` (`shared/library.js`), or the lesson named by `after: '<title>'`, which starts a branch (a fork splits the road into two lanes that meet again at the world's goal). A stop unlocks once the stop before it is cleared. A lesson in the **same unit** as the stop before it opens with a recap of that lesson (`from.url` set). A lesson that **starts a new unit** (including the first lesson after a fork into a new unit) opens with a **warm-up** instead: a `review` stage whose `from` names what the child already knows (no url), e.g. `{ title: 'Living things you already know', emoji: '🌳' }`. Its facts and questions draw on everyday or earlier knowledge the lesson builds on, without giving away the lesson's content. `tools/lesson-check.js` checks both rules.

**What he finds tricky (`parents.html`):** `shared/engine.js` saves the first try at every question in `y3:tries` (`track(kind, q, first)`): reading checks, recaps and warm-ups, video quests, quizzes, boss battles, questions inside games (`runQuestions`) and spelling-test words (with his first wrong spelling). The parent page shows what is still tricky, each lesson's first-try score and what he has since got right. Challenger NPCs put up to 2 of his last-time misses into their 3 questions. New question flows should call `track` too.

**Where the engine code lives:** `shared/engine.js` is the core (stages, questions, navigation, gems). Games and the boss battle are parts in `shared/engine/`: games (the everyday games: sort, label, match, order, truefalse, fixit, questions, wordsearch, crossword, mystery), stages (the teach, case and investigate stages), arcade, science, earth, number, time, world, future, spelling, breaks and boss. Every lesson loads games, breaks and boss; the core loads the rest only when a lesson needs them (`PARTS` at the bottom of engine.js), so lesson pages don't change. Add a new game to the part for its kind, and keep files under about 1,500 lines.

**Smoke test (after changing anything in `shared/`):** `npm install` once, then `node tools/smoke.js` (about 5 minutes; or name lesson files to test just those). It opens every lesson in a simulated browser, renders every stage and game round, and plays the question stages to the end with the right answers. Anything that throws an error or can't be finished is listed. A quick test script for a new game can borrow its simulated browser: `const { open, answer, moveOn, wait } = require('./tools/smoke.js')`.

**Check every new or changed lesson:** `node tools/lesson-check.js <file>` validates the data (answer indexes, evidence answers found on the page, hotspot and slider answers you can actually reach, runner items with both right and wrong words). Reading-page checks can be multiple choice or a hands-on type (`evidence`, `hotspot`, `slider`, `oddone`, `build`, `type`, `predict`, `setclock`), but not `tf`, `gap` or `order`.

**Keep lessons varied (check with `node tools/activity-audit.js`):**
- At most ONE word puzzle (`crossword` or `wordsearch`) per lesson, and none in about half of lessons. Never in two lessons in a row of the same world. Other vocabulary practice: `build`, picture↔word `match`, `type`.
- Don't repeat an arcade game (`invaders`, `runner`, `platformer`, `blocks`) from the previous lesson of the same world.
- **No giveaway lengths:** the right answer must not be the longest option. Write wrong answers about as long and as plausible as the right one, and make the short one right just as often (activity-audit flags a right answer 40%+ and 6+ letters longer than every other option; `--long` lists them). Kids spot the pattern and stop reading.
- **At least 3 typed questions per lesson** (`type`), because typing stops button-spamming. Only ask for words the lesson has already taught (on the page or in the video) before the question.
- Multiple choice should be at most 60% of a lesson's questions. Mix in `evidence` and `type` reading checks, `hotspot` for pictures and diagrams, `slider` for numbers, and `oddone` / `predict` for reasoning.
- Every activity must make the child do the lesson's thinking (recall, apply, explain, predict, create). A game only wraps that thinking.
- Don't repeat the previous lesson's stage order. A lesson's second read stage can become one of three stages that teach the same facts (see the top of `shared/engine.js` for their fields), and two lessons next to each other on a road shouldn't use the same one:
  - `teach` (🤖 Teach the robot): Professor Bolt teaches the topic line by line and some lines have one wrong word. The child taps it, then taps the right word, or presses "That's right!". Numbers need `wrongAt` (word index). Lines have no [[glossary]], bold or HTML, and at least one line is right.
  - `case` (🕵️ Detective case): a case file (`mystery`), clue questions that pin clue cards to an evidence board, then a `solve` inference question and a `closed` ending. Use **bold**, not HTML. The solve options are just the suspects, with no reasons (so the case file has to be read: who used which rock, who said which code). Then **Prove it!**: the child taps the clue card that proves the answer (`solve.proof`: clue index from 0, or a list; `proofQ` is the prompt, e.g. "Which clue proves Robin and Hedgehog wrong?"). The proof must be ONE clue (or a few), not any of them. A wrong card shakes, and after two misses the proof glows. The solve `explain` waits for the case-closed screen. The case closes with a detective rank (accusation and proof both first try = 🥇 Super Sleuth, one = 🥈, none = 🥉) and a bonus gem for each, earned once.
  - `investigate` (🧪 Investigation): `predict` (never wrong; `answer` says what really happens), a `test` round (a simulation with missions: `windtest`, `garden`, `ramp`, `forces`, `pollinate`, or a maths tool like `timehops`), `explain` questions, then a `result`.

**Question-writing rules (so children read rather than scan):**
- Answers are shuffled automatically, so write the right answer anywhere. Use `keepOrder: true` only if the order matters.
- Reading-page checks should test understanding, not word-matching. Ask about a **new example** or a **"what would happen if…"**, and word the right answer differently from the page. Avoid "X is called a…" questions where the answer is the highlighted word.
- Keep **bold** out of reading-page text (yellow [[glossary]] words are fine). Never bold the exact phrase a question asks about.
- Wrong options should be believable, not silly, at least for the reading checks.
- Only a first-try answer earns the gem on a reading page; a wrong guess makes the child re-read for a few seconds.
**Read to me:** every reading card and recap gets a 🔊 Read to me button automatically (built-in British voice, free). Each word lights up as it is spoken (read-along), and it stops when the page changes. While it reads, the button is locked (no restarting mid-page), and every 🔊 Hear-it button ignores taps until the current word or sentence has been spoken, so neither can be spammed. No lesson data needed.
**Text tricks:** `**bold**` and `[[word]]` (tappable glossary word — add the word to `glossary`).
