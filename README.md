# Pixelkid 🎮

Fun, game-style interactive lessons for a Year 3 learner (UK National Curriculum, age 7–8): reading quests, video quests, games and a boss-battle quiz.

**Play:** https://stevetodoro.github.io/Pixelkid/

- Works in any browser — on an iPad, use Safari → Share → *Add to Home Screen*.
- Progress and gems are saved on each device.
- Lesson ideas and how to add a new lesson: see [TOPICS.md](TOPICS.md).
